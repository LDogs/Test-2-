STUDY DESK MI.IS.MAN — VERSIONE MOBILE PWA
==========================================

IMPORTANTE
Un file HTML aperto dall'app File di iPhone/iPad non può garantire il funzionamento completo di Study Desk. Per installare la versione come app e usare il service worker è necessario pubblicare questa cartella su un indirizzo HTTPS. Questo ZIP NON è un'app App Store o un APK.

CONTENUTO
- index.html: versione aggiornata PC/mobile con esame avanzato e alternative simili
- manifest.webmanifest: metadati per installazione PWA
- sw.js: cache locale della shell dell'app
- icons/: icone

COME PUBBLICARLA
1. Estrai la cartella StudyDesk_Mobile_PWA.
2. Pubblica tutti i file e le sottocartelle su un hosting statico HTTPS affidabile (ad esempio GitHub Pages, se hai un account). Mantieni la struttura delle cartelle.
3. Apri l'URL HTTPS pubblicato.

IPHONE / IPAD
1. Apri l'URL in Safari.
2. Tocca Condividi.
3. Seleziona Aggiungi alla schermata Home.
4. Conferma. Avvia Study Desk dalla nuova icona.

ANDROID
1. Apri l'URL HTTPS in Chrome.
2. Apri il menu ⋮ e scegli Installa app oppure Aggiungi a schermata Home.

FUNZIONI E LIMITI
- L'interfaccia è responsive per PC, tablet e telefoni.
- Il service worker memorizza la shell applicativa dopo la prima visita online; OCR/librerie esterne potrebbero richiedere Internet al primo uso.
- Documenti e progressi sono memorizzati localmente sul dispositivo/browser. Non si sincronizzano automaticamente tra PC e mobile. Esporta un backup prima di trasferire o sostituire versioni.
- Non include API IA e non è un'app nativa.
- Le domande sono esercitazioni originali, non domande ufficiali RFI/SAMAC.

PRIVACY
La pubblicazione HTTPS serve a distribuire i file dell'app. I documenti restano nel database locale del browser salvo che l'utente scelga di esportarli; le librerie esterne possono essere richieste da Internet.
